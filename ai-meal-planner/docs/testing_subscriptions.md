# Тестирование подписок (AppHud + StoreKit)

## Как тестировать покупки без списания денег

### 1. Sandbox-аккаунт Apple

- В **App Store Connect** → **Users and Access** → **Sandbox** → **Testers** создайте тестовый аккаунт (отдельный email, не ваш основной Apple ID).
- На устройстве **не выходите** из основного Apple ID в настройках. Sandbox-аккаунт используется только для запросов покупок.

### 2. Где входить в Sandbox

- **iOS**: первый запрос покупки в приложении откроет системный диалог входа. Войдите **туда** своим **Sandbox**-аккаунтом. В интерфейсе будет указано **Environment: Sandbox**.
- **Настройки**: **Настройки → App Store → внизу «Песочница» (Sandbox)** — там можно сменить/проверить тестовый аккаунт.

### 3. Если постоянно просит войти (зацикливание)

Частые причины:

1. **В диалоге покупки входите основным Apple ID**  
   Нужно вводить именно **Sandbox**-аккаунт из App Store Connect.

2. **Симулятор**  
   На симуляторе IAP часто ведёт себя нестабильно. Надёжнее тестировать на **реальном устройстве** (подключённом по USB, выбранном в Xcode/Flutter как target).

3. **Старые незавершённые транзакции**  
   Удалите приложение с устройства, переустановите и попробуйте покупку снова (с Sandbox-аккаунтом).

4. **Продукты не в «Ready to Submit»**  
   В App Store Connect у подписок (Weekly/Monthly) статус должен быть **Ready to Submit**, и они привязаны к приложению и к paywall в AppHud.

### 4. Локальное тестирование без Sandbox (Xcode)

Можно тестировать экраны и логику без входа в Apple ID:

- В Xcode: **File → New → File → StoreKit Configuration File**.
- Добавьте продукты с теми же **Product ID**, что и в AppHud (например `sonicforge_weekly`, `sonicforge_monthly`).
- В схеме приложения: **Edit Scheme → Run → Options** → **StoreKit Configuration** выберите этот файл.
- Запуск из Xcode будет использовать локальные продукты; запрос входа в Apple ID может не появляться или вести себя иначе. Для проверки реального диалога и восстановления покупок используйте Sandbox на устройстве.

### 5. Краткий чеклист

- [ ] В App Store Connect создан Sandbox Tester.
- [ ] В диалоге покупки вводите именно Sandbox-аккаунт (в интерфейсе видно Sandbox).
- [ ] По возможности тест на реальном устройстве, не на симуляторе.
- [ ] При зацикливании входа: удалить приложение, переустановить, снова войти Sandbox только в диалоге покупки.

---

**FormatException в логах**: сообщение вида «The data couldn't be read because it isn't in the correct format» часто приходит из кэша (история планов/лента) или из ответа API при некорректных данных. На работу подписок и покупок это обычно не влияет; при необходимости можно сбросить данные приложения (удалить и установить заново).
