### 2. Интеграция монетизации

**AppHud (Подписки)**
- Полная интеграция SDK для управления подписками
- Реализован listener для отслеживания изменений статуса подписки в реальном времени
- Методы проверки статуса подписки, покупки и восстановления покупок
- Получение данных: placements, paywalls, продукты через `paywall.products`
- Отображение стоимости подписок через `ApphudProduct.skProduct.price` и `currencyCode`
- Интеграция атрибуции: передача данных из AppsFlyer, Firebase в AppHud
- API Key: `app_Z44sHCCXqhP5FCBDa8SxKBLB7VLpga`
- Bundle ID: `com.nicfuno.sonicforgeflow`
- Paywall ID: `main_paywall`
- Product IDs: `sonicforge_weekly`, `sonicforge_monthly`

**AdMob (Реклама)**
- Интеграция Google Mobile Ads SDK
- Реализованы типы рекламы:
  - **Banner**: отображается внизу экранов генерации и ленты
  - **Interstitial**: показывается после успешной генерации плана (макс. 1 раз в 3 минуты)
  - **App Open**: на холодном старте/возобновлении приложения (макс. 1 за сессию)
  - **Rewarded**: подготовлено для будущего использования (опциональная разблокировка функций)
- Использование тестовых ID для разработки и реальных для production
- Автоматическая обработка ошибок загрузки рекламы
- Тестовые Ad Unit IDs настроены для обеих платформ

5. **Deep linking** — настроить deep links через AppsFlyer для отслеживания установок из рекламных кампаний и корректной атрибуции.

6. **GDPR/CCPA compliance** — добавить полноценную систему согласий для пользователей из ЕС и Калифорнии.

7. **Revenue optimization** — интегрировать медиацию рекламы (AppLovin, ironSource) для увеличения eCPM через конкурентные торги.
